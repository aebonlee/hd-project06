# 사내 Copilot용 엔진 사양서 추출 프롬프트 템플릿 (요구사항 3.1.1)

엔진 업체가 보내온 사양서(PDF / PPT / 엑셀 — 양식 무관)를 **표준 엑셀 양식**으로
정리할 때 사용하는 프롬프트입니다.

> **주의(대외비)**: 엔진 사양서는 사내 대외비 자료이므로 반드시 **사내 Copilot**에만
> 업로드하세요. 외부 AI 서비스(챗봇·번역기 포함) 업로드 금지. 이 웹페이지 자체는
> 어떤 AI/외부 서버도 호출하지 않으며, Copilot은 "사양서 → 엑셀 정리" 단계에만 사용합니다.

## 사용 방법

1. 사내 Copilot 대화창에 엔진 사양서 파일을 첨부한다.
2. 아래 프롬프트 전체를 복사해 붙여넣고 실행한다.
3. Copilot이 출력한 표를 `templates/엔진사양_표준양식.xlsx` 의 `engines` / `curves`
   시트에 붙여넣는다 (schema 시트는 그대로 둔다).
4. 웹페이지(index.html)에서 **엑셀 Import** 로 불러온다.
5. 확인 후 **엑셀 Export** 로 저장하면 같은 양식의 통합 DB 파일이 만들어진다.

---

## 붙여넣을 프롬프트 (여기부터 복사)

```
당신은 지게차 엔진 설계 담당자를 돕는 데이터 정리 도우미입니다.
첨부한 엔진 사양서에서 아래 항목만 골라 "표준 엑셀 양식"으로 정리해 주세요.

[출력 형식 — 표 2개]

표 1: engines (엔진 1개당 1행)
아래 21개 열을 이 순서 그대로, 첫 행은 열 이름(항목 키)으로 출력하세요.
값을 찾을 수 없는 칸은 비워 두세요. 단위 환산이 필요하면 지정 단위로 환산하세요.

| 항목 키             | 의미                       | 단위/형식                          |
|---------------------|----------------------------|------------------------------------|
| manufacturer        | 엔진 제조사                | 텍스트                             |
| engine_model        | 엔진 모델명                | 텍스트 (정확한 형식명)             |
| forklift_models     | 적용 지게차 모델           | 쉼표로 구분한 목록 (예: HF250D-9, HF300D-9) |
| rated_power_kw      | 정격 출력                  | kW 숫자만 (PS/HP면 kW로 환산: 1PS=0.7355kW, 1HP=0.7457kW) |
| rated_power_rpm     | 정격 출력 RPM              | rpm 숫자만                         |
| max_torque_nm       | 최대 토크                  | Nm 숫자만 (kgf·m면 x9.80665)       |
| max_torque_rpm      | 최대 토크 RPM              | rpm 숫자만                         |
| low_idle_rpm        | Low Idle RPM               | rpm 숫자만                         |
| high_idle_rpm       | High Idle RPM              | rpm 숫자만                         |
| weight_kg           | 무게(건조 중량 기준)       | kg 숫자만                          |
| engine_type         | 엔진 타입                  | "기계식" 또는 "전자식"             |
| cylinders           | 실린더 수                  | 숫자만                             |
| displacement_cc     | 배기량                     | cc 숫자만 (L이면 x1000)            |
| oil_capacity_l      | 오일 용량                  | L 숫자만                           |
| coolant_capacity_l  | 냉각수 용량(엔진측)        | L 숫자만                           |
| fuel_consumption    | 연비(정격점 연료소비율)    | g/kWh 숫자만                       |
| alternator          | 알터네이터 스펙            | 텍스트 (예: 24V 45A)               |
| starter_motor_kw    | 스타터 모터 출력           | kW 숫자만                          |
| emission_cert       | 배기 규제 인증             | 텍스트 (예: Tier 4 Final, Stage V) |
| aftertreatment      | 후처리장치 타입            | 텍스트 (예: DOC + DPF, SCR, 없음)  |

표 2: curves (성능 곡선 — RPM 포인트 1개당 1행)
사양서의 성능 곡선(Performance Curve) 그래프 또는 표에서 RPM별 출력·토크 값을
읽어 아래 4개 열로 출력하세요. 첫 행은 열 이름 그대로 사용하세요.
그래프만 있고 수치 표가 없으면 눈금을 기준으로 8~12개 지점을 읽고,
읽은 값이 추정치임을 표 아래에 한 줄로 알려 주세요.

| 엔진 모델명 | RPM | 출력(kW) | 토크(Nm) |

[규칙]
1. 사양서에 없는 값은 추측하지 말고 빈칸으로 두고, 마지막에 "누락 항목" 목록을 정리해 주세요.
2. 숫자 칸에는 단위·콤마 없이 숫자만 쓰세요. (예: 55.3)
3. rated_power_kw / rated_power_rpm / max_torque_nm / max_torque_rpm 은
   표 2의 곡선 값과 일치해야 합니다. 곡선과 요약표 수치가 다르면 곡선 기준으로 쓰고
   차이를 비고로 알려 주세요.
4. 같은 사양서에 엔진이 여러 개면 engines 표에 여러 행으로 정리하세요.
5. 결과는 엑셀에 바로 붙여넣을 수 있게 표 형태로만 출력하세요.
```

## (선택) 항목이 추가된 경우

관리 항목을 추가했다면(요구사항 3.1.2, README "항목 추가 방법" 참고) 위 프롬프트의
표 1에 추가한 항목 키 행을 같은 형식으로 한 줄 덧붙이면 됩니다.
예: `| warranty_hours | 엔진 보증 수명 | 시간 숫자만 |`
