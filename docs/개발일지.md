# 개발일지 — 지게차 엔진 사양 관리·비교 웹페이지 (hd-project06)

- 프로젝트: 엔진 사양 DB(엑셀) 관리 + RPM별 출력·토크 곡선 + 최대 4개 엔진 비교
- 기획: 홍근영 (생성형 AI 업무자동화 전문가과정 1차수)
- 개발 기간: 2026-08-21
- 저장소: https://github.com/aebonlee/hd-project06

## 1. 요구사항 분석

엔진사별로 양식·파일 형식(PDF/PPT/엑셀)이 제각각인 사양서에서 필요한 제원만 골라 **수기 입력**하는 현재 업무를 다음 체계로 대체한다.

```
사양서 → (사내 Copilot + 제공 프롬프트) → 표준 엑셀 양식 → 웹페이지 Import
  → 엔진/지게차 모델 검색 조회 (제원 표 4그룹 + 출력·토크 곡선)
  → 최대 4개 엔진 비교 → Export (Import와 완전 동일 양식)
```

핵심 제약 두 가지가 설계를 지배했다.
- **사내 대외비**: 외부 AI API 호출 금지 → 추출 단계는 사내 Copilot 프롬프트 템플릿으로 대체, 웹은 Import부터 담당
- **사내망/오프라인**: 외부 네트워크 의존 금지 → 라이브러리 전부 로컬 동봉, `file://`로 열어도 동작

참고: 기획자 시제품 `engine_curve_R1.zip`은 전달받지 못해 기획서 지침("없으면 새로 만든다")에 따라 신규 구현했다. 추후 zip 제공 시 비교·반영 가능하다.

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| **스키마를 데이터로 관리** — 엑셀 3번 시트 `schema`(항목 키·표시명·그룹·단위·순서)가 화면 렌더링을 구동 | 요구 3.1.2: "엔진 보증 수명" 같은 항목 추가가 **코드 수정 없이** 엑셀 열 추가만으로 가능해야 함. 스키마에 없는 열도 "기타" 그룹으로 표시·Export 보존 |
| Import/Export를 같은 모듈(`js/data.js`)의 대칭 함수로 구현 | 요구 3.1.4 "양식 완전 동일" — 왕복(Import→Export→재Import) 동일성을 자동 테스트로 보장 |
| Chart.js + annotation 플러그인 (로컬 동봉) | 정격 출력·최대 토크 **상시 라벨**(3.2.1.3) 요구에 annotation이 적합. 이중 Y축(출력/토크)과 두 차트 분리 토글 병행 |
| 비교 곡선의 색상 + 선 스타일(출력 실선/토크 점선) 이중 인코딩 | 최대 4개 엔진 × 2개 곡선 = 8개 선의 판독성 확보 (색약 대응 포함) |
| localStorage 세션 보존 + Export가 영속 저장소 | 기획 전제: "엑셀 파일이 데이터베이스의 기준" — 다른 PC 이관은 Export 파일로 |

## 3. 구현 내역 (요구사항 ID 기준)

- **3.1.1**: `docs/copilot_프롬프트.md` — 사양서를 표준 양식으로 변환하는 사내 Copilot용 프롬프트(21개 항목 키·단위·환산 규칙·curves 표 형식, 대외비 주의 문구, 항목 추가 시 확장법)
- **3.1.2**: 스키마 시트 기반 렌더링(4그룹: 기본 정보/성능/주요 제원/규제·인증), 미등록 열 "기타" 그룹 처리
- **3.1.3/3.1.4**: SheetJS Import/Export (3시트: engines·curves·schema), 빈 표준 양식 + 샘플 채운 양식 제공
- **3.2**: 엔진 모델명·적용 지게차 모델 검색, 사이드바 목록, 제원 표
- **3.2.1.1~4**: 꺾은선+점 표시, 점 클릭 시 `50.2kW @ 1600 rpm` 형식 값 표시(고정 판독 영역 포함), 정격/최대 상시 주석 라벨, 출력·토크 축별 Y축 범위 입력·초기화
- **3.3 / 3.2.2.1~2**: 최대 4개 선택(체크박스 제한), 엔진당 1컬럼 비교 표 — 왼쪽 컬럼과 동일 값은 `<-` 표기(숫자는 수치 동등, 텍스트는 트림 후 일치), 곡선 겹쳐 그리기(엔진별 색상, 주석 토글)
- **샘플 데이터**: `make_samples.py` — 제조사 3곳·엔진 6개·엔진당 RPM 포인트 9~11개, 토크는 중속 피크·출력은 정격 RPM 피크의 현실적 곡선, 정격/최대값이 곡선 데이터와 정확히 일치

## 4. 테스트 및 검증

- `node test/roundtrip.test.js` — **11/11 통과**: Import→Export→재Import 심층 비교, 2회전 안정성, 임베디드 샘플 == xlsx 동일성, 빈 양식, **열 추가 왕복**(3.1.2 검증)
- `node test/logic.test.js` — **13/13 통과**: `<-` 표기 의미론(왼쪽 이웃 비교), 4개 제한, 스키마 그룹핑·기타 fallback·순서 삽입, 검색, 포맷팅
- headless 렌더링 검증: 샘플 로드→검색→조회(4그룹)→점 클릭 판독→차트 분리→Y축 범위 적용→3개 엔진 비교(`<-` 5셀, 곡선 6개 겹침)까지 전 시나리오, **콘솔 에러 0건**
- 스크린샷 검수로 발견한 시각 버그 2건(축 상단 라벨 잘림, 분리 모드 여백) 수정 완료
